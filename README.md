## 데이터 구조 및 엑셀 매핑

### 1. 편제표 (`SUBJECTS_2026` / `SUBJECTS_2025`)

**출처:** `2026학년도 입학생 교육과정 학점 배당표_1학년.xlsx`  
(2025 입학생도 동일 편제 확인됨 → 두 변수 동일 내용)

각 과목은 아래 구조로 정의됨:

```js
{ id:'sc5', name:'물리학', type:'il', grade:2, sem:1 }
```

| 필드 | 설명 |
|------|------|
| `id` | 고유 ID. 교과군 prefix + 번호 (k=국어, m=수학, e=영어, h=한국사, s=사회, sc=과학, p=체육, a=예술, t=기술정보, l=제2외국어, c=진로) |
| `name` | 과목명 |
| `type` | `il`=공통·일반, `jin`=진로, `fus`=융합 |
| `grade` | 학년 (1~3) |
| `sem` | 학기 (1~2) |

편제표는 6열(1-1, 1-2, 2-1, 2-2, 3-1, 3-2)로 표시됨.

### 2. 학과별 권장교과 (`DEPT_DATA.depts`)

**출처:** `2028학년도 권역별 대학별 권장과목(반영과목).xlsx`

#### 엑셀 구조

| 열 | 내용 |
|----|------|
| C | 대학명 |
| D | 모집단위 (계열/학과명) |
| F | **핵심과목** (필수적 이수 권장) |
| G | **권장과목** (가급적 이수 권장) |

전국 대학 × 학과 조합 약 1,360행으로 구성됨.

#### 매핑 방법

1. 앱에 정의된 37개 학과 각각에 대해 매칭 키워드 목록을 작성  
   예) `'물리'` → `['물리학과']`

2. 엑셀 모집단위명에 키워드가 포함된 행을 전부 수집  
   (오매칭 방지: `화학과` ↔ `중국어문화학과`, `의과대학` ↔ `수의과대학` 등 블랙리스트 처리)

3. 수집된 모든 행의 핵심과목·권장과목 텍스트를 쉼표로 분리 후 정규화  
   (로마숫자 변환, 괄호 제거, `또는`/`및` → 쉼표 등)

4. 과목명 → 앱 ID 변환 테이블로 매핑  
   예) `'물리학'` → `sc5`, `'미적분Ⅱ'` → `m7`, `'사회'(교과군)` → `['s3','s5']`

5. 등장 빈도 순으로 정렬 후 상위 5개를 `core`, 그 외 상위 4개를 `rec`으로 선택

6. `ref`는 엑셀 근거 없으므로 전부 `[]` — **담당교사가 직접 채워야 함**

#### 앱 코드 형식

```js
'학과명': {
  comment: '학과 안내 코멘트',
  core: ['과목id', ...],  // 핵심권장 (엑셀 핵심과목 기반)
  rec:  ['과목id', ...],  // 권장      (엑셀 권장과목 기반)
  ref:  ['과목id', ...],  // 참고      (미입력 → 교사 직접 작성)
}
```

#### 엑셀 데이터 없는 학과 (core/rec 모두 빈 배열)

심리, 언론, 수학교육, 과학교육, 사회교육, 체육교육, 음악, 무용  
→ 엑셀에 해당 학과명 행이 존재하지 않아 매핑 불가. 교사가 직접 입력 필요.

## 데이터 수동 수정 방법

`index.html` 내 `DEPT_DATA.depts` 객체에서 해당 학과를 찾아 수정:

```js
'심리': {
  comment: '기존 코멘트 유지',
  core: ['s5', 'm4', 'sc7'],  // 직접 추가
  rec:  ['s3', 'e3'],
  ref:  [],
},
```

과목 ID 목록은 같은 파일 내 `SUBJECTS_2026` 객체 참조.
