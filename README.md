## 데이터 구조 및 엑셀 매핑

### 1. 편제표 (`SUBJECTS_2026` / `SUBJECTS_2025`)

**출처**
- `SUBJECTS_2026`: `2026학년도 입학생 교육과정 학점 배당표_1학년.xlsx`
- `SUBJECTS_2025`: `2025학년도 입학생 교육과정 학점 배당표_2학년.xlsx`

각 과목은 아래 구조로 정의됨:

```js
{ id:'sc5', name:'물리학', type:'il', grade:2, sem:1 }
```

| 필드 | 설명 |
|------|------|
| `id` | 고유 ID. 교과군 prefix + 번호 (k=국어, m=수학, e=영어, h=한국사, s=사회, sc=과학, p=체육, a=예술, t=기술정보, l=제2외국어, c=진로) |
| `name` | 과목명 |
| `type` | `il`=공통·일반, `jin`=진로, `fus`=융합 |
| `grade` | 학년 (1~3) |
| `sem` | 학기 (1~2) |

편제표는 각 엑셀 입학생 시트 7~105행에서 학점/선택학점 값이 있는 학기 칸만 개설 과목으로 반영함.
- B열은 교과군 판별에만 사용함.
- 실제 과목명은 D열만 사용함.
병합된 학점 셀은 병합 범위 전체에 전파해 읽음.
현재 `SUBJECTS_2026`, `SUBJECTS_2025`는 각각 103개 칸을 반영함.
같은 과목이 여러 학기 선택군에 반복되면 같은 ID를 여러 칸에 표시함.

### 2. 학과별 권장교과 (`DEPT_DATA.depts`)

**출처:** `2028학년도 권역별 대학별 권장과목(반영과목).xlsx`

#### 엑셀 구조

| 열 | 내용 |
|----|------|
| C | 대학명 |
| D/E | 모집단위 (병합값을 E 학과명으로 전파, 분리 시 E값 사용) |
| F | **핵심과목** (필수적 이수 권장) |
| G | **권장과목** (가급적 이수 권장) |
| H | (앱에서 사용 안 함) |
| I | 참고 과목명 (`ref`, 병합 셀 전파) |
| J | 앱 comment 초안 |

전국 대학 × 학과 조합 약 1,360행으로 구성됨.

#### 매핑 방법

1. 앱에 정의된 43개 학과 각각에 대해 `scripts/update_from_excel.py`의 `MATCH_KEYWORDS`로 모집단위 행을 매칭

2. 엑셀 모집단위명에 키워드가 포함된 행을 전부 수집
   - D/E가 병합된 행은 병합값을 E 학과명으로 전파해 사용
   - D/E가 분리된 행은 E값을 실제 학과명으로 사용

3. 수집된 행의 F열은 `core`, G열은 `rec`로만 반영
   - 병합 셀은 좌상단 값을 병합 범위 전체에 전파해 읽음
   - F/G 권장과목 영역의 병합 셀 값은 모두 `core`로 반영

4. 엑셀에 명시된 과목명이 앱 편제표 과목명과 직접 매칭되는 경우만 ID로 변환
   - `수학(확률, 미적분)`처럼 교과군 뒤 괄호에 세부 과목이 있으면 괄호 안 과목을 개별 매핑
   - `확률`은 `확률과 통계`, `미적분`은 `미적분Ⅰ`·`미적분Ⅱ`로 매핑

5. `국어`, `영어`, `수학`, `사회`, `과학` 같은 교과군 표현은 특정 과목으로 확장하지 않음

6. I열 과목명만 `ref`로 반영 (병합 범위는 F/G와 같이 좌상단 값 전파)

7. H열은 앱에서 읽지 않음

8. J열 코멘트 초안은 `comment`로 반영

#### 앱 코드 형식

```js
'학과명': {
  comment: '코멘트 초안',
  core: ['과목id', ...],  // 핵심권장 (엑셀 핵심과목 기반)
  rec:  ['과목id', ...],  // 권장      (엑셀 권장과목 기반)
  ref:  ['과목id', ...],  // 참고      (엑셀 I열 기반)
}
```

#### core/rec 빈 배열 학과

언론, 국제관계, 미술, 음악, 무용

이 학과들은 매칭 행이 없거나, F/G열이 일반 문구·교과군 표현이라 특정 과목 ID로 변환하지 않음.

```bash
.venv/bin/python scripts/update_from_excel.py
```

